# Kept

Meeting-mode app for Even G2 glasses that catches the promises you make out loud
and turns them into Notion tasks and Google Calendar deadlines with one tap.

Heads Up: Even Realities Hackathon · Track 04 · AI Assistants & Work

## What existed before Nov 23
- Official Even Hub SDK (`@evenrealities/even_hub_sdk`), CLI and simulator
- Official `evenhub-templates/minimal` (used only as a reference)
- Nothing else. All Kept code is written during the hackathon.
